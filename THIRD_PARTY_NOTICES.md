\## Chess-Tracker Reference



Early experimentation for this project was informed by the Chess-Tracker project by yaseralie:



https://github.com/yaseralie/Chess-Tracker



That project demonstrated chessboard tracking concepts using Python and OpenCV and served as an early reference while exploring the idea.



ChessAI later evolved into a separate Android/Kotlin implementation with Android screen capture, real-time overlays, virtual board-state tracking, Stockfish integration, and additional move-detection and recovery systems.



No license was identified in the referenced Chess-Tracker repository at the time this notice was written.
